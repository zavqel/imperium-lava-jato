# IMPÉRIUM — estrutura refinada

Fluxo principal:
**Início → Serviços e valores → Montar atendimento → Escolher horário**

## Páginas
- `index.html`: apresentação, quem somos, forma de trabalho, avaliações e contato.
- `servicos.html`: catálogo e valores. As descrições estão marcadas para substituição.
- `montar.html`: configurador do atendimento.
- `agendamento.html`: etapa de escolha do horário após o atendimento ser montado.
- `promocoes.html`: página separada para promoções, preparada para futuro painel administrativo.

## Pastas
Neste projeto atual, CSS, JS e a logo ficam na raiz para preservar compatibilidade com o GitHub Pages.

## Próxima etapa
