# IMPÉRIUM — Site

Base do novo site do IMPÉRIUM Lava Jato e Estacionamento.

## Estrutura
- `index.html` — página principal.
- `style.css` — identidade visual e responsividade.
- `app.js` — configurador inicial, serviços de exemplo e protótipo da agenda.
- `logo-imperium.jpg` — logo oficial fornecida pelo IMPÉRIUM, usada sem alteração.
