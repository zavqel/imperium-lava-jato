# IMPÉRIUM — Site

Primeira base do novo site do IMPÉRIUM Lava Jato e Estacionamento.

## Estrutura

- `index.html` — página principal.
- `css/style.css` — identidade visual e responsividade.
- `js/app.js` — configurador inicial, serviços de exemplo e protótipo da agenda.
- `assets/logo-imperium.jpg` — logo fornecida pelo IMPÉRIUM, usada sem alteração.
